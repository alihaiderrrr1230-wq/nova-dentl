## 🧪 اختبر:

### المرضى:
1. روح **العيادة** → اضغط "إضافة مريض جديد"
2. جرب تضيف مريض بعمرك 25 → اختبر كل الحقول
3. جرّب تضيف مريض عمره 8 سنوات → راح تشوف badge "طفل" وردي
4. استخدم البحث (اكتب "أحمد")
5. اضغط "تعديل" على أي مريض
6. اضغط "حذف" → يتأكد قبل الحذف

### الحجوزات:
1. روح **الحجوزات** → اضغط "إضافة حجز"
2. اختار مريض + تاريخ + وقت → حفظ
3. راح تشوف الحجز في قائمة اليوم المختار
4. بدّل التاريخ بالسهام (سابق/تالي)
5. اضغط "تعديل" → غيّر الحالة من "مجدول" لـ "مكتمل"
6. فلتر بـ "مكتمل" → راح تشوف بس الحجوزات المكتملة

### المخزن:
1. روح **المخزن** → اضغط "إضافة مادة"
2. أدخل: مخدر موضعي، فئة "تخدير"، كمية 4، حد التنبيه 5 → حفظ
3. راح تشوف المادة بلون برتقالي (مخزون منخفض) ⚠️
4. روح **الداشبورد** → راح تشوف تنبيه في "تنبيهات المخزن"
5. جرّب تضيف مادة بتاريخ انتهاء قريب (مثال: بعد 30 يوم)
6. راح تشوف تحذير "30 يوم" بجانبها
7. اضغط "مخزون منخفض فقط" → يعرض بس المواد اللي تحتاج إعادة طلب
