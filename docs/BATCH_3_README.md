## ✅ شو تشوف بعد التشغيل:

1. **شريط تنقل علوي** (Navbar) زجاجي يطلع في كل الصفحات
2. **من الرئيسية → العيادة** → تشوف قائمة المرضى (6 مرضى)
3. **اضغط على أي مريض** → يفتح **مخطط الأسنان التفاعلي**
4. **اضغط على أي سن** → popup فيه:
   - اختيار الجزء (تاج / جذر / كلاهما)
   - قائمة الـ 12 مرض
   - اختر مرض → السن يتلون فوراً
5. **اختبر على مرضى بأعمار مختلفة**:
   - مريض عمره > 10 → مخطط كبار (32 سن)
   - مريض عمره < 10 (يوسف 9 سنوات) → مخطط صغار (20 سن لبني)

---

## 🎨 مميزات المخطط:

| الميزة | الوصف |
|---|---|
| **دقة الرسم** | كل سن مرسوم بتاج + جذر بشكل حقيقي (4 أنواع أسنان: قاطع، ناب، ضاحك، ضرس) |
| **تفاعل كامل** | hover + click + scale animation |
| **تلوين** | كل مرض بلون مختلف (12 لون) |
| **أمراض متعددة** | نفس السن يقدر يحمل عدة أمراض بألوان مختلفة |
| **تقويم** | ينرسم تلقائياً (سلك + بريسز) |
| **صغار/كبار** | يبدّل تلقائياً حسب عمر المريض |
| **إحصائيات** | عدد الأسنان المصابة، أمراض التاج/الجذر |
| **حفظ تلقائي** | كل تغيير ينحفظ في localStorage |

## 🧪 اختبر هالأشياء:

1. افتح مخطط **أحمد (32 سنة)** → راح تشوف 32 سن دائمة
2. افتح مخطط **يوسف (9 سنوات)** → راح تشوف 20 سن لبني (51-85)
3. اضغط على **سن #16** (ضرس) → اختر "تسوس" على التاج → راح يتلون أحمر
4. اضغط نفس السن مرة ثانية → اختر "خراج" على الجذر → راح يتلون بلونين
5. اضغط سن ثاني → اختر "تقويم" على "كلاهما" → راح يظهر سلك التقويم
